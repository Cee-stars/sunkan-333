          文を編集

          この1文だけを直します。収録の 360 文は書き換えず、この端末の中に上書きだけを覚えます （「元に戻す」でいつでも収録の文に戻せます）。

          音声の設定

          英語を読み上げる声を選べます。入っている声は端末ごとに違うので、 この設定はこの端末だけのものです（同期しません）。

          自分のデータを読み込む

          Google スプレッドシートで「左に日本語・右に英語」の2列を選んでコピーし、そのまま下に貼り付けてください。 タブ区切り・カンマ区切りのどちらでも読み込めます。

          保存済みの自作セット

            パラフレを追加

            見出しに元の 1 文、その下に言い換えを 4 つまで入れられます。 日本語の意味は空のままでもかまいません。

            見出し（元の 1 文）
            言い換え（4 つまで）

            ジャンル

            ジャンルはいくつでも作れます。消してもパラフレは残り、「ジャンルなし」に移ります。

              表でまとめて出し入れする

              1 行が 1 枚です。左から ジャンル / 見出しの英文 / 見出しの意味 / 言い換え1の英文 / 言い換え1の意味 … の順で、言い換えは 4 つまで（全 11 列）。タブ区切り・カンマ区切りのどちらでも読み込めます。 見出し行が付いていれば自動で外します。

              いま表示しているパラフレ

              ジャンルの絞り込み・検索で表示されているぶんが対象です。

              送ると「パラフレ帳（ジャンル名）」というセットができ、同じ日本語に対する言い換えが 1 文ずつ並びます。元のパラフレはそのまま残ります。

              iPhone・MacBook で揃える

              自作セット・足した文・★・パラフレ帳を、端末どうしで揃えます。 収録の 360 文と、隠し方・文字サイズなどの設定はそのままです（端末ごとの好みのため）。 どちらの端末で足したものも消えません。足りないほうに入るだけです。

              かんたんに渡す（登録なし）

              片方の端末でリンクを作り、もう片方で開くだけです。アカウントも設定も要りません。 思い出したときに手で渡す形で、放っておいて勝手に揃うわけではありません。

              リンクはメモ・メッセージ・AirDrop などで自分に送ってください。 文が多くてリンクに収まらないときは、ファイルのほうを使います（AirDrop で送れます）。

              貼り付けて受け取る

              ホーム画面から開いたアプリにはアドレス欄が無く、リンクを開けません。 そのときは、もう片方の端末で作ったリンクをここに貼り付けてください。 My Dictionary の「リンクをコピー」で作ったものも、そのまま受け取れます。

              放っておいても揃うようにする（GitHub を使う）

              こちらは 最初に一度だけ登録が要りますが、そのあとは開くたびに自動で揃います。 GitHub の「シークレット Gist」（URL を知っている人だけが見られる場所）に置きます。 完全に非公開というわけではない点にご注意ください。 入れたトークンはこの端末の中だけに保存され、GitHub 以外へは送りません。

              GitHub でトークンを作る … Note は何でもよく、権限（scope）は gist だけで足ります。 My Dictionary 用に作ったトークンがあれば、それをそのまま使えます。

              1 台目：空のまま下の「保存先を新しく作る」を押すと、ここに入ります。
              2 台目：1 台目のこの値をそのまま貼り付けます。 My Dictionary と同じ Gist ID でもかまいません（中では別のファイルに分けて置きます）。

              自動で同期する

              ほかの端末・アプリをつなぐ

              この設定をまるごとリンクにして渡します。受け取った側は貼り付けるだけで、 そのあとは何もしなくても自動で揃います（トークンの入力は要りません）。 このリンクにはトークンが入っているので、人に渡さないでください。

              やめるとき

              この端末からトークンと Gist ID を消します。覚えた文はそのまま残ります。
