# Instant English

英語を「書く・その時に言う・聞き取る」ための 3 つのモードを、1 つにまとめたアプリです。
iPhone と MacBook の両方で気持ちよく使えます。

上のタブで **瞬間英作文** / **場面** / **リスニング** を行き来できます。最後に開いていたものを覚えています。

| モード | 何をするところ |
| --- | --- |
| **瞬間英作文** | 日本語を読んで、その場で英語にする。表と、英語を隠す機能だけ |
| **場面** | 「トイレが空いてない」のような**その時**に言えるようにする。言い方を 3 本まで並べる。写真も付けられる |
| **リスニング** | 英文を 🔈 の右に並べ、かたまりごとに出していく（はじめはぼかしてある）。プレイリストで分けられる |

## できること（瞬間英作文）

- **スプレッドシートと同じ2列表示** — 左に日本語、右に英語。iPhone の縦画面でも2列のまま崩れません。
- **英語を隠す** — 行をタップ（クリック）すると、その行だけ答えが出ます。上のボタンで全部まとめて隠す／出すも可能。
- **隠し方を選べる** — ぼかす／塗りつぶす／空白にする の3種類。
- **逆向き** — 英語を読んで日本語にする向きにも切り替えられます。
- **アプリの中で1文ずつ足せる** — 思いついた文をその場で追加。追加 → 欄が空になる → また追加、と続けて入れられます。
- **セットも自分で作れる** — 名前を決めて空のセットを新規作成し、そこに1文ずつ溜めていけます。表を用意しなくても始められます。
- **PDF から作れる** — 決まった書き方の PDF を選ぶだけで、日本語 → 英語の組が並びます。書き方がバラバラな PDF は「AI への指示をコピー」で整えてから。**`EN / JA / EX / EXJA` の書き方の PDF もそのまま使えます**（例文のほうが出題に回ります）。
- **自分のデータを読み込める** — Google スプレッドシートで2列を選んでコピーし、貼り付けるだけ。TSV / CSV 両対応。
- **音声は自動** — 読み上げは文字から合成するので、追加した文にも何もしなくても音声が付きます。設定で「表示したら自動で読み上げる」もオンにできます。
- **収録例文 360 文** — be動詞・一般動詞・時制・助動詞・完了/受動態・使える文型 の6セット。
- **↻「もう一度」** — 間違えた文に付けて、あとで「もう一度」だけ表示。言えるようになったら外します。
- **どれくらい言えるか（40 / 80 / 100%）** — 文ごとに印を付けて、**まだ言えないものだけ**を並べて練習できます。印を選ぶと、**次にいつ出すか**も自動で決まります（忘却曲線）。
- **つまずいた所** — 言えなかった語をタップして残すと、「**よくつまずく語**」が溜まっていきます。
- **場面** — 「トイレが空いてない」のような**その時**に言えるようにします。答えを 1 つに決めず、**言い方を 3 本まで同じ太さで**並べます。写真も付けられます。
- **1文ずつ直せる** — 行の ✎ から、その1文の日本語・英語・メモを書き換えられます。収録の 360 文も直せて、**元データは書き換えません**。「元に戻す」でいつでも収録の文へ戻せます。
- **読み上げ** — 英語を音声で確認できます（対応ブラウザのみ）。☰ メニューの「音声の設定」で**声を選べます**（Samantha など、端末に入っている英語の声から）。「聞いてみる」でその場で確かめられます。
- **検索・シャッフル・文字サイズ変更・ダークモード自動対応**
- **My Dictionary から受け取れる** — 別アプリ（My Dictionary）で 📤 を押した文が、上に「取り込む」として届きます。
- **iPhone と MacBook で揃う** — 自作セット・足した文・書き換えた文・「もう一度」・場面・リスニングを、端末どうしで同期できます。
- **古いままにならない** — 新しい版が出ていると上に帯が出ます。画面の一部だけが古い（本体は新しいのに見た目が変わらない）場合も見つけて知らせます。「更新する」を押せば、溜まっている古い一式を捨てて読み直します（⚙ 設定の「最新にする」でも同じ）。
- **メニュー（☰）** — 持ち出しと端末まわりを 1 か所に。iPhone では下から出ます。
- **ぜんぶ書き出す（機種変更用）** — ☰ メニューから。JSON ファイル 1 つに、**モードぜんぶ**（自作セット・足した文・書き換えた文・「もう一度」・場面・リスニング・覚えた記録・写真）がまとめて入ります。畳んだモード（パラフレ帳・カード）のぶんも、残っていればそのまま入るので消えません。**機種変更のときはこちらです。**
- **このセットだけ書き出す** — いま開いているセットの 日本語 / 英語 / メモ を、Excel などで開ける CSV に。日本語が化けないようにしてあります。1 つのセットだけ人に渡したいときや、表で直したいときはこちら。
- **読み込む** — 上のどちらで書き出したものも、同じ「読み込む」で戻せます（JSON と CSV は中身で見分けます）。
- **オフラインで動く** — 一度開けば電波がなくても使えます。ホーム画面に追加すればアプリのように起動します。

## My Dictionary から送る

単語帳アプリ **My Dictionary** で覚えた表現を、そのまま瞬間英作文の出題に回せます。

1. My Dictionary で項目の 📤 を押す
2. 「英文」「日本語」「型（任意）」を確かめて **送る**
3. 瞬間英作文を開くと上に「**「My Dictionary」から 2 件届いています**」と出るので **取り込む**

取り込むと「My Dictionary」というセットに入り、いつもどおり日本語を見て英作文する形になります。
型を入れておくと、答えを表示したときにメモとして一緒に出ます。

**英文と日本語の両方がそろっているものだけ送れます。** 瞬間英作文は「日本語 → 英文」で出すので、
`late` のような単語だけだと出題できないからです。My Dictionary 側の送信画面で、例文があれば
自動で埋まり、無ければその場で文の形に直せます。一度送った項目には「送信済み」が付くので、
同じものを何度も送らずに済みます（間違って二度送っても、同じ文は取り込みのときに省かれます）。

### 仕組み

2 つのアプリは同じ GitHub Pages のドメインにパス違いで置かれています
（`…github.io/dictionary-22/` と `…github.io/sunkan-333/`）。localStorage はオリジン単位なので、
`sunkan:inbox` という 1 つのキーを受け渡し場所にできます。サーバーもアカウントも要りません。

ただし **iPhone では、ホーム画面に追加したアプリとブラウザで保存領域が分かれます。**
片方をホーム画面から、もう片方を Safari から開いていると、localStorage は共有されません。
そのため My Dictionary 側には「**瞬間英作文で開く**」という受け渡し用のボタンがあり、
送ったカードを URL に載せて開きます。URL なら保存領域が分かれていても必ず届きます。
どちらの道で来たものも、同じ文は取り込みのときに省かれるので、二重に並ぶことはありません。

いずれにしても **同じ端末の中だけ**の受け渡しで、機種をまたぐことはありません。

## iPhone と MacBook で揃える

自作セット・足した文・「もう一度」・場面・リスニングを、端末どうしで揃えられます。**⚙ 設定 → 同期の設定** から。

やり方は 2 つあります。

| | 端末に入れるもの | 向いている場面 |
| --- | --- | --- |
| **自分の置き場**（おすすめ） | 置き場の URL ＋ **合言葉だけ** | ふだんの 2 台 |
| GitHub | トークン ＋ Gist ID | My Dictionary からカードを受け取るとき |

**おすすめは「自分の置き場」です。** GitHub のトークンを端末に持たせずに済むので、
万一 合言葉 が漏れても、見られるのはこのアプリの中身だけで、ほかのサービスには影響しません。
置き場は Cloudflare の無料枠で足ります（使いすぎても勝手に課金はされず、止まるだけです）。

置き場の作り方は `cloudflare/worker.mjs` の先頭に書いてあります（npm もビルドも要りません）。
できたら、**1 台目**で URL を入れて「合言葉を作る」→「いま同期する」。
**2 台目**には、**同じ URL と同じ合言葉を入れるだけ**です。

合言葉は AirDrop か自分宛てのメモで渡してください。**人に見える所に貼らないでください**
（これが唯一の鍵です）。繋がらないときは「うまくいかないとき」を押すと、
URL・合言葉・置き場の設定のどこで止まっているかを教えてくれます。

**GitHub のほうは消していません。** 同じ Gist が My Dictionary からカードを受け取る口を
兼ねているためです。両方入れておいて、置き場のほうを使う形でかまいません。
やり方は 2 つあり、**どちらも「どちらの端末で足したものも消えない」**のは同じです。

### かんたんに渡す（登録なし）

片方の端末で「**リンクを作ってコピー**」を押し、メモ・メッセージ・AirDrop などで自分に送って、
**もう片方で開くだけ**です。アカウントもトークンも要りません。

文が多くてリンクに収まらないときは「**ファイルに書き出す**」→ AirDrop などで送って、
向こうで「**ファイルを読み込む**」。こちらは大きさの制限がありません。

**ホーム画面に追加したアプリが相手のときは、リンクを開けません**（アドレス欄が無いため）。
そのときは渡す側で「**リンクをコピー**」して、受け取る側の同じ画面にある
「**貼り付けて受け取る**」に貼り付けてください。My Dictionary の 🔗 で作ったリンクも、
同じところで受け取れます。

**思い出したときに手で渡す形**で、放っておいて勝手に揃うわけではありません。
自動で揃えたい場合は、下の GitHub を使うほうを設定してください。

> このアプリはサーバーを持たない（GitHub Pages に置いた HTML だけの）作りなので、
> **どこかに登録しないかぎり、裏で勝手に同期する仕組みは作れません。**
> データを預ける先が無いためです。iCloud も、Safari のブックマークやパスワードは同期しますが、
> **アプリのデータ（localStorage）は同期しません。**

### 放っておいても揃うようにする（GitHub を使う）

最初に一度だけ登録すれば、あとは開くたびに自動で揃います。GitHub の「シークレット Gist」
（**URL を知っている人だけが見られる場所**）を置き場として使います。
**完全に非公開というわけではない**点にご注意ください。

**用意するのは 1 回だけ**です。そのあとは、どの端末・どのアプリでも何もしなくて構いません。

#### 1 回目（どれか 1 つのアプリで）

1. [GitHub でトークンを作る](https://github.com/settings/tokens/new)。Note は何でもよく、
   権限（scope）は **gist** だけにチェックすれば足ります
2. ⚙ 設定 → 同期の設定 → トークンを貼って「**保存先を新しく作る**」
   （ここで自動同期も一緒に入ります）
3. 「**つなぐリンクをコピー**」

#### 2 つ目から（トークンの入力は要りません）

コピーした**つなぐリンクを貼り付けるだけ**です。

- 瞬間英作文 … ⚙ 設定 → 同期の設定 → 「貼り付けて受け取る」
- My Dictionary … メニュー → 同期の設定 → 「つなぐリンクを貼り付ける」

ホーム画面に追加したアプリにはアドレス欄が無く、リンクを開けません。貼り付けなら届きます。
**つなぐリンクにはトークンが入っているので、人に渡さないでください。**

つないだあとは、My Dictionary で 📤 送ったカードも、そのままメインの瞬間英作文に出ます。

### 決まりごと（どちらのやり方でも同じ）

- **どちらの端末で足したものも消えません。** 両方から拾って 1 つにまとめます
  （時刻で丸ごと勝ち負けを付けると、片方がしばらくオフラインだった間の追加が消えるため）
- **消したものは、もう片方でも消えます。** 消した記録を持ち回ります。消したあとに同じ文を
  足し直せば、そちらが生きます
- **同期しないもの**: 隠し方・文字サイズ・逆向きなどの設定（端末ごとの好みのため）と、収録の 360 文
- **失敗したときは手元のデータに手を付けません。** 向こうが読めないときは、空と解釈せずに
  同期そのものを止めます（相手にしか無いものを塗りつぶさないため）
- トークンは**その端末の中だけ**に保存され、GitHub 以外へは送りません

My Dictionary にも同じ仕組みの同期があります（メニュー → 同期の設定）。**トークンは使い回せます。**
Gist ID も同じもので構いません（中では別のファイルに分けて置きます）。

### どれくらい言えるかで分ける

同じセットの中でも、もう口から出る文と、まだ詰まる文が混ざります。1 文ずつ
**40% / 80% / 100%** の印を付けて、**まだ言えないものだけ**を並べられます。

**付け方**: 行の右に **まだ** と出る欄があります（**英語を隠したままでも出ています**。
開かないと押せないのでは、隠している意味がないため）。押して **まだ / 40% / 80% / 100%**
から選びます。付けた印は日本語の先頭に小さく出るので、表を眺めたままどれがまだかを
見分けられます。

**絞り方**: セット名の隣の欄で選びます。右に件数が出るので、開く前に残りが分かります。

| 選ぶもの | 出るもの |
| --- | --- |
| ぜんぶ | 全部 |
| 今日 | **今日やるぶん**（下の「次にいつ出るか」を見てください） |
| 〜80% | **80% に届いていないものだけ**（まだ・40%）。ふだんの練習はこれ |
| 〜100% | 100% に届いていないものだけ（まだ・40%・80%） |
| まだ / 40% / 80% / 100% | その印のものだけ |

絞っている最中に印を変えると、その行は表から外れます。黙って消えると探すことになるので、
「80% にしました。…表には出ていません。」と理由を出します。

印は**端末どうしで揃います**（同期を設定している場合）。同じ文を別の端末で付け替えたときは、
**あとから付けたほうが勝ちます** — 100% にしたものを別の端末で 40% に下げたら、ちゃんと下がります。
どの絞り込みを選んでいるかは端末ごとの好みなので、揃えません。

### 次にいつ出るかは自動で決まる（忘却曲線）

**印を選ぶことが、そのまま自己採点になります。** 覚えた記録のためのボタンは足していません。
選んだ瞬間に次いつ出すかが決まり、「**80% にしました。次は 3日後。**」と画面に出ます。

| 選んだもの | 意味 |
| --- | --- |
| まだ | もう一度 |
| 40% | むずかしい |
| 80% | できた |
| 100% | かんたん |

**↻「もう一度」を付けたときも、「言えなかった」として記録されます。** 段階の欄は何も付けて
いない行では最初から「まだ」と出ているので、**その行では「まだ」を選べません**（同じものを
選び直すことになるため）。言えなかったことを残せる操作が ↻ しかないので、こちらでも数えます。
外すときは数えません（印を消すだけ）。↻ は知らせを出しません（答えがいつも「今日」で、
言うことが無いため）。

**「今日」で絞ると**、予定が来た文と、**まだ一度も採点していない文**が出ます。はじめは全部が
これに入り、採点するたびに減っていきます。

締めは「**今日の終わり**」で切っています。「もう一度」と採点した文は 10 分後に置き直されますが、
「いま」で切ると、たったいま「まだ」にした文が目の前から消えてしまうためです
（1 枚ずつ出す画面なら並べ直しに見えますが、こちらは一覧なので消失に見えます）。

計算は**場面とまったく同じ FSRS-5**（`assets/srs.js`）です。保存先だけ別で、
予定も**端末どうしで揃います**（最後に答えたのが新しいほうを残します）。

### つまずいた所（言えなかった語を残す）

「言えた／言えなかった」だけだと、**どこで**詰まったのかが残りません。瞬間英作文は
言い切って終わるので、同じ所で何度つまずいても気づけないままになります。

**付け方**: 英語を開くと、行の右に **△** が出ます（答えを見てから付けるものなので、
↻ や % と違って閉じている行には出しません）。押すと文が語に分かれて出るので、
**言えなかった語をタップ**します。タップしただけで保存されます（「保存」は押しません）。
印の付いた行は △ に色が付きます。

**見方**: ☰ メニュー →「**よくつまずく語**」。付けた語を**セットをまたいで**多い順に数えます。
どの語で詰まるかはセットごとの話ではないので、分けて数えても仕方がないためです。

数えるときは語を**均します**（小文字にして前後の記号を落とす）。`Brother.` と `brother` を
別に数えると、集計が意味を持たなくなるためです。

印は**端末どうしで揃います**（**あとから付けたほうが勝ち**。足し算にすると、片方で外した語が
もう片方から戻ってきて消せなくなります）。

## 場面

「トイレに行ったら空いてなくて、人に聞きたい」——そういう**その時**に言えるようにするモードです。
中身は空から始まります。

### 「答え」を置かない

言い方は一つではありません。固定の正解を出すと、**自分の言い方がそれと違ったときに
間違いに感じて**しまいます。そこでこのモードは、答えではなく**促し**を出します。

```
どんな時  トイレが空いてない
「他にトイレありますか？」と言ってみよう

   短く      Any other restrooms?
   やわらかく  Is there another one I could use?
   遠回しに   Do you know if there's another restroom?
```

**言い方は 3 本まで。どれも同じ太さで並びます。**
1 本目を太字にすると、それが「答え」になって残りが間違いに見えるためです。
札は**上下ではなく方向**（短く／やわらかく／遠回しに）なので、どれを言っても外れません。
1 本しか入れていなければ、札も出ません。

### 足し方

**言いたかったことを 1 行書くだけで保存できます。** 英語も写真も「どんな時」も、
ぜんぶ後から足せます。その「時」は突然来るので、欄をいくつも埋めさせると入れられなくなるからです。
英語をまだ入れていない行には「英語まだ」と出ます。

ファイルからも読み込めます（テキスト・表・PDF）。表の列は左から **日本語 / 英語 / どんな時 / メモ**。
書き方の見出しは `どんな時:` ですが、**前に書き出した `場面:` のファイルもそのまま読めます**。

### 印

**「出なかった／詰まった／言えた」の 3 つ**です。数字は出しません（小さくて読めないため）。
基準は「書いてある英語と一致したか」ではなく、**口から出たか**です。

- **出なかった** — 言いたいことは浮かぶが、英語が出ない
- **詰まった** — 出たが詰まった、または 1 本だけ
- **言えた** — 詰まらずに言えた

選ぶと「**『詰まった』にしました。次は 3日後。**」と出ます。これは成績ではなく
**次にいつ出すか**を決めるものです（瞬間英作文と同じ忘却曲線を使っています）。

### 写真

**写真は無くても成立します。** 付けた行にだけ 🖼 が出て、押すと大きく見られます。
付いていない行には枠も出しません（枠があると「写真を入れろ」と催促しているように見えるため）。

トイレの前やお店で写真は撮りにくいので、**後からまとめて付ける**使い方で構いません。

> このモードは、以前「フレーズ」という名前でした。**表示名だけを変えています。**
> 保存しているデータはそのままなので、前に入れたものは消えていません。

## リスニング

英文を**かたまりごとに**出していく練習です。聞こえたぶんだけ自分で開けていくので、
**どこで聞き取れていないのか**が自分で分かります。中身は空から始まります。

### 作り

- 行は**左に 🔈、右に英文**。押すと英語が鳴ります
- **まだ出していないかたまりはぼかしてあります**（`filter: blur`）。
  はじめから字が読めると耳を使わなくなるため
- **行をタップすると、かたまりが 1 つずつ**出ます。出したかたまりは色が変わり、
  その日本語が下に小さく出ます
- **ぜんぶ出したあと、もう一度タップすると最初に戻ります**。同じ文を何度でも回せます

### 文の入れ方

「＋追加」で 1 文ずつ。英文は `Let's get / a cup of coffee / after this.` のように
**スラッシュでかたまりに区切って**入れます（区切りがそのまま出す単位になります）。
日本語も同じようにスラッシュで区切れますが、無くてもかまいません。

**入力欄の Enter では保存しません**（日本語を変換して確定する Enter で
勝手に保存されないようにするため）。保存するのはボタンだけです。

ダイアログの**いちばん上は「入れ先」**（どのプレイリストに入れるか）です。
どこに入るのかを、書き始める前に見せます。初期値は**いま選んでいるプレイリスト**。

保存先は `sunkan:listen:decks` / `sunkan:listen:items` / `sunkan:listen:stars` /
`sunkan:listen:ui`。1 件は `{id, en, ja, note, deck, created}` で、
**`deck` が空文字なら「未分類」**です。

### プレイリスト（文を分ける）

文が増えると「今日はこのへんだけ聞きたい」が効かなくなるので、
**プレイリスト**で分けられます（瞬間英作文の「セット」と同じ考え方です）。

- 操作列の**いちばん上の欄**で選びます。「すべて（n）」／各プレイリスト（n）／
  「未分類（n）」で、選ぶとその文だけになります。**件数も欄に出ます**
- 選んだものは覚えています（`sunkan:listen:ui`。端末ごとの好みなので**同期しません**）
- 作るのは「＋ 新しいプレイリスト」から。**名前が空では作れず、同じ名前も作れません**
  （同じ名前が 2 つあると、どちらに入れたのか分からなくなるため）
- 名前はあとから変えられます。**消しても中の文は消えません** —
  `deck` が空文字に戻って「未分類」に並びます（聞く文は本人の持ちもので、
  入れ物を片付けただけで消えては困るため）
- **前から入れてあった文にはプレイリストがありません。** 読むときに「未分類」へ
  揃えるので、今まで入れたものがどこかへ消えることはありません

> 前にあった**シャドーイング**は、このリスニングに入れ替えて画面を外しました。
> **入れてあった文（`sunkan:shadow:*`）は消していません。**


## 使い方

### そのまま開く

`index.html` をブラウザで開くだけで動きます。ビルド不要・依存パッケージなしの素の HTML/CSS/JS です。

ローカルで動かすなら（サービスワーカーを効かせるには `file://` ではなく HTTP が必要です）:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

### iPhone のホーム画面に追加する

1. Safari でアプリを開く
2. 共有ボタン → 「ホーム画面に追加」
3. アイコンから起動すると、アドレスバーなしの全画面で立ち上がります

**アイコンを新しくしたときは、入れ直すまで古いアイコンのままです。** iOS はホーム画面に
追加した時点のアイコンと名前を控えて持つので、配信しても既存のものは変わりません。
そして **入れ直す（削除 → 追加し直す）と、そのアプリが持っていたデータは消えます**
（iOS はホーム画面のアプリとブラウザで保存領域を分けているため）。

入れ直すときは必ずこの順で:

1. ☰ →「ぜんぶ書き出す」でバックアップを取る（同期を設定してあるなら、同期しておく）
2. ホーム画面から削除 → Safari で開き直す → 共有 → ホーム画面に追加
3. 書き出したファイルを読み込む（同期なら、つなぎ直す）

### 自分のセットを作る

1. 右上の「＋追加」を開く
2. 下の「新しいセットを作る」に名前を入れて「作る」

空のセットができてすぐ開くので、そのまま1文目から入れていけます。作ったセットは「自作セット」に並び、いらなくなったら「表からまとめて読み込む」の中の一覧から削除できます。

### 1文ずつ足す

1. 右上の「＋追加」（または一覧のいちばん下の「＋ 文を追加」）を開く
2. 日本語と英語を入れて「追加する」

入れるとすぐ一覧の末尾に並びます。欄が空になるので、そのまま次の文を続けて入れられます。追加した文には番号の横に ＋ が付き、その行の 🗑 でいつでも消せます（収録の文は消えません）。

**音声の用意は要りません。** 読み上げは文字から合成しているので、足した文もそのまま 🔈 で読み上げられます。

### 1文だけ直す

1. 行をタップして開く（「もう一度」が付いている行・いま見ている行でもかまいません）
2. 行の右に出る **✎** を押す
3. 日本語・英語・メモを直して「保存する」

収録の 360 文も直せます。**元のデータは書き換えません。** 直した内容だけを別に覚えて、
表示するときに上から当てているので、ダイアログの「**元に戻す**」でいつでも収録の文へ戻せます。

直しても「もう一度」は外れません（印は文そのものではなく行に付いています）。書き換えた内容も
「元に戻す」も、同期していれば他の端末に伝わります。

自分で足した文には「元に戻す」は出ません（戻す先の元の文がないためです）。

### PDF から作る

1. 上の「**📄 PDF から**」を押す
2. **入れ先**を選ぶ（いま開いているセットが初期値です）
3. 「**PDF を選ぶ**」

（「＋追加」→「表からまとめて読み込む」からも同じ画面が開きます）

**すでにあるセットに足せます。** いちばん上の「入れ先」で選ぶだけです。
毎回 新しいセットを作らされると、少し足したいだけでもセットが増えていって続きません。
**収録の 360 文にも足せます**（元データは書き換えず、後ろに足すだけです）。
新しいセットを作りたいときだけ「＋ 新しいセットを作る」を選ぶと、名前の欄が出ます。

決まった書き方の PDF なら、そのまま読み込めます。

```
# セット: 中1レベル

JA: 私は毎朝コーヒーを飲みます。
EN: I drink coffee every morning.
---
JA: 彼女は見た目も気性も母親に似ている。
EN: She takes after her mother in both looks and temper.
MEMO: take after = 〜に似ている
```

- 見出しは `JA` `EN` `MEMO` の 3 つだけ（`日本語: 英語: メモ:` でも通ります）
- `---` が 1 組の区切り。`MEMO` は空でもかまいません
- **PDF で長い文が途中で折り返されていても、続きとしてつなげて読みます**
- 「書き方の見本をダウンロード」で、この形の見本が手に入ります

**`EN / JA / EX / EXJA` の書き方の PDF も、そのまま読み込めます。**
そのときは**例文のほうを出題に回し**、見出しの語は答え合わせのときのメモに入ります。
瞬間英作文は文を口に出す練習なので、`take after` のような語だけでは出題にならないためです。
**単語帳向けに作った PDF を、そのまま瞬間英作文の出題に回せます。**

書き方がバラバラな PDF は「**AI への指示をコピー**」を押して、ChatGPT や Claude に
**PDF といっしょに**渡してください。返ってきた文字を貼り付ければ同じ形になります。

文字ではなく**画像として取り込まれた PDF は読めません**（その場合も AI の道が使えます）。

### スプレッドシートからまとめて入れる

1. Google スプレッドシートで、日本語の列と英語の列（2列）を選んでコピー
2. 「＋追加」→ 下の「表からまとめて読み込む」を開く
3. セット名を入れて、そのまま貼り付け → 「読み込む」

3列目まで入れておくと、メモとして扱われます。データはブラウザの中（localStorage）にだけ保存されます。

## キーボード操作（MacBook）

| キー | 動作 |
| --- | --- |
| `↑` `↓` | 行を移動 |
| `Space` / `Enter` | いまの行の英語を表示／非表示 |
| `A` | 全部表示／全部非表示 |
| `S` | いまの行を「もう一度」に入れる／外す |
| `/` | 検索へ |
| `Esc` | 検索を消す／ダイアログを閉じる |
| `←` `→` | モードを切り替え（上のタブにフォーカスがあるとき） |

`↑↓` などの行の操作は瞬間英作文のときだけ効きます。ほかのモードを開いている間はキーを取りません。

## 中身

```
index.html                  画面の構造（DOM の定義）
assets/style.css            見た目すべて（iPhone / MacBook / ライト・ダーク）
assets/data.js              収録例文 360 文
assets/app.js               瞬間英作文の動作すべて
assets/mode.js              タブでのモード切り替えだけ
assets/media.js             写真（IndexedDB）。縮めて詰めるのもここ。画面は触らない
assets/srs.js               忘却曲線（FSRS）。予定の計算だけ。DOM も保存も触らない
assets/phrase.js            場面（その時に言えるようにする）
assets/listen.js            リスニング（かたまりごとに出す・ぼかし・🔈）
assets/import.js            取り込み（PDF・テキスト・表・AI への指示）。3 モード共通
assets/inbox.js             受信箱（別アプリから届いたカードの取り込み）
assets/sync.js              端末どうしの同期（GitHub の Gist 経由）
assets/speech.js            読み上げ（端末ごとの癖はここに閉じ込めてある）
assets/update.js            版ずれの検知と、古い一式を捨てて読み直す道
assets/vendor/pdf.min.js    pdf.js（Mozilla / Apache-2.0）。PDF を選んだときだけ読み込む
version.json                公開されている版（APP_VERSION と同じ文字列）
manifest.webmanifest, sw.js ホーム画面追加とオフライン対応
CONTRACT.md                 ファイル間の取り決め
```

フレームワークもビルドツールも使っていません。`assets/data.js` を書き換えれば収録例文をそのまま差し替えられます。

外から持ってきているのは `assets/vendor/` の **pdf.js** だけです（PDF の文字を取り出すため）。
1.5MB あるので起動では読まず、**PDF を選んだときに初めて**読み込みます。一度使えばキャッシュに入り、
そのあとはオフラインでも PDF を読めます。CDN は使っていません。

## 版を上げる

次の 3 か所を**同じ文字列**にして、`sw.js` の `CACHE` を 1 つ上げます。

- `assets/app.js` の `APP_VERSION`
- `version.json` の `build`
- `index.html` の `<meta name="sunkan-build">`

4 つとも上げないと、更新が届かなかったり、出るはずのない「新しい版があります」の
帯が出続けたりします。`index.html` の meta を忘れると、**画面が古いままなのに
「最新です」と言う**状態になります（これはいちばん困るので気をつけてください）。

逆に meta だけ古いまま残すと、**「画面の一部が古いままです」の帯が、
「更新する」を押しても消えなくなります**（食い違いが配信物そのものにあるので、
利用者の側では直しようがない）。実際に一度やりました。

**`index.html` が読む js / css にも、同じ番号を付けます。**

```html
<link rel="stylesheet" href="assets/style.css?v=47">
<script src="assets/app.js?v=47"></script>
```

付けておくと、**新しいページには必ず新しい一式が当たります**（URL ごと変わるので、
端末に溜まっている古いほうは使われない）。付け忘れると、新しい画面に古い js が当たって
「ボタンはあるのに何も起きない」状態になります。実際に一度やりました。
画像（アイコン）は付けません。中身が変わっても画面の作りとはずれないためです。

**この食い違いは公開の手前で止まります。** GitHub Actions が 3 か所の文字列と、
js / css に付いた番号を照合し、1 つでも違えば公開せずに失敗します
（`.github/workflows/pages.yml`）。
手元で確かめるなら:

```sh
sed -n 's/.*<meta name="sunkan-build" content="\([^"]*\)".*/\1/p' index.html
sed -n "s/.*var APP_VERSION = '\([^']*\)'.*/\1/p" assets/app.js
sed -n 's/.*"build"[^"]*"\([^"]*\)".*/\1/p' version.json
```

## 公開する

`main` に push すると GitHub Pages に自動で公開されます（リポジトリの Settings → Pages で Source を **GitHub Actions** にしておいてください）。
